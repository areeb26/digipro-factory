# Digital Product Factory

A Python-based automated system for creating, managing, and publishing digital products.

## Project Structure

```
/digital-product-factory/
├── /trend_monitor/          # Monitor and scrape trending topics
├── /product_creators/       # Create various digital products
├── /marketing_gen/          # Generate marketing content
├── /review_dashboard/       # Review and manage products
├── /platform_publishers/    # Publish to various platforms
├── /data/                   # Database and data storage
├── requirements.txt         # Python dependencies
├── config.yaml             # Configuration settings
└── .env.example            # Environment variables template
```

## Setup

1. Clone the repository
2. Copy `.env.example` to `.env` and fill in your API keys
3. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
